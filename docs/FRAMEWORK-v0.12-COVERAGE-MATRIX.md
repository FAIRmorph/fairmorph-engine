## Specific findings and resolutions

1. **Full-product language in older docs:** Main README, older foundation notes and acceptance report used wording inconsistent with the P0.5 PoC. Updated primary entrypoints and labeled early stage notes as historical. No claim of full v0.12 compliance, general publication readiness or production-grade storage.
2. **Profile-bundle identity:** Original framework v0.12 `schemas/metadata-envelope.schema.json` refers to `provenance-entry.schema.json` by a relative reference. Executable P0.5 bundle embeds the entry in local `$defs` to avoid remote resolution. This can be **semantically equivalent while still changing schema SHA-256**. Before schema-1.0 standardization, compare the executable bundle with original schemas mechanically and choose one canonical versioned representation; do not claim unchanged byte digests.
3. **Row/cell lineage:** Framework chapters 13/15 prescribe source-cell observability in previews/tests. Generic P0.3 RUN deliberately minimizes persistent audit to deterministic pins + mapping rules + actual value changes. Persisted **full cell-lineage** is not delivered. Retain the stronger source explanation/validation as an explicit P0.6/P0.8 acceptance item.
4. **Strict profile prerequisite:** Any semantic Entity pipeline without approved exact P0.5 profile pins fails before execution. Pure technical import remains unmapped. Old unprofiled PoC Entity pipeline formats are **intentionally unsupported**, not to be migrated.
5. **CI evidence interpretation:** 129 green tests on both platforms means the selected synthetic vertical modules pass. It does not verify the numerical targets of a real CS-PHOC dataset, a second independent scientific dataset, or long-running Workbench/export workflows.
6. **Forward-only change policy:** The original chapters include later-product migration obligations. Before framework document v1.0 these are **not** mandatory; coordinate contract revisions in code, tests and docs and retain immutable completed evidence.

**Acceptance statement:** The architecture and artifacts have been checked for their P0.1–P0.5 **vertical PoC scope**, with explicitly listed open contracts. The entire v0.12 framework is **not** closed or scientifically certified. Following docs-only changes, verify the final branch CI before PR #10 merge.
