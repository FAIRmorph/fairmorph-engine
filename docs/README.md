## Terminology reviewers should distinguish

**Original input** means external, unchanged research bytes. **SourceFieldDefinition** means a separately versioned statement of field meaning, possibly only a draft. **Mapping** means an explicit transformation decision. **RUN/2** means a deterministic, version-pinned technical execution record. **Verification** means integrity checks passed, not ecological or publication approval.

The Engine provides **two separate execution families**: the reviewed CSV-mapping reference workflow and a generic declarative DAG/Entity workflow. Their produced artifacts differ; do not assume a single export implementation covers both.

The [fairmorph-validations repository](https://github.com/FAIRmorph/fairmorph-validations) creates several **CS-PHOC-specific test exports** that are **not** generated by the Engine's generic publication adapter. Its independent real-data checks do not test the Workbench.

## Evidence and maturity

Use the repository's current GitHub Actions and tests for current synthetic technical evidence; use the independent validations project's pinned tests for actual CS-PHOC data evidence. Neither is a replacement for field-revision review, approved entity mappings or publication decisions.

The framework is pre-1.0; experimental schemas, CLIs, contracts and storage format may change consistently across code, tests and documentation. Original source objects and completed immutable RUN evidence must not be modified silently.
