# FAIRmorph Engine

FAIRmorph Engine is a local-first **Python** curation and transformation proof of concept. It is not the FAIRmorph Workbench.

Start with the [complete user guide](USER-GUIDE.md) to run and verify a small dataset, or see the [documentation index](README.md) for advanced workflows, contracts, operations, and real-data validation evidence.
