# CS-PHOC Engine mapping regression

This directory is a **bounded Engine integration test**, not a separate
publication implementation or an approved scientific data product.

The primary real-data CS-PHOC reproducibility and export-content validation
lives in [fairmorph-validations](https://github.com/FAIRmorph/fairmorph-validations/blob/main/docs/CS-PHOC-REPRODUCTION-AND-RESULTS.md).
That repository executes the generic declarative Engine RUN/2 and produces
**dataset-specific test-only** DwC-A, PANGAEA-preparation TSV and GeoJSON
outputs. Those files are not generated by a universal Engine publisher, and
the Workbench is not exercised by that validation.

## Run the mapping regression

From the Engine repository root, with Python 3.11+:

```bash
python -m pip install -e ".[dev]"
python -m pytest -q examples/cs-phoc/tests/test_reference_workflow.py
```

The test creates a temporary project, imports the two bundled CS-PHOC CSV
fixtures without changing their source bytes, stages and explicitly confirms
the example mapping, executes the reviewed CSV-mapping workflow, verifies
RUN artifacts and exports an Engine **Data Package** (not a DwC-A).

It checks all **16,940 recorded source-category cells** against the RUN
output, including **11,599 explicit zeros** and a category-value sum of
**79,232**. These are source counts, not an estimate of seal population size.
The test's example review action does not constitute scientific approval or
source-author endorsement.

## Files retained here

| File | Purpose |
| --- | --- |
| `cs-phoc-counts.csv`, `cs-phoc-events.csv` | Fixed regression inputs |
| `mapping-profile.json` | Explicit example source-to-target CSV mapping and zero/missing-value policies |
| `tests/test_reference_workflow.py` | CLI regression for `stage-csv-mapping` → `approve-mapping` → `run-mapping`, source-cell comparison, Data Package export and verification |

The historical, example-specific EML/DwC-A converter and its entry-point
script have been removed. Publication behavior should be tested through the
Engine's generic publication APIs or the independent validation repository,
without maintaining a second CS-PHOC-specific exporter in this repository.

For routine Engine usage with smaller synthetic inputs, start with the
[Engine user guide](../../docs/USER-GUIDE.md).
